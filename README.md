# 🎓 Website PKKMB IKKHG 2026

Website resmi untuk kegiatan **PKKMB (Pengenalan Kehidupan Kampus bagi Mahasiswa Baru)** Institut Kesehatan Karsa Husada Garut tahun 2026.

---

## 📌 Deskripsi

Website ini dibuat sebagai media informasi utama bagi mahasiswa baru untuk mengakses seluruh kebutuhan selama kegiatan PKKMB, mulai dari jadwal kegiatan, tata tertib, hingga dokumentasi acara.

---

## 🚀 Fitur Utama

* 🏠 **Beranda (Landing Page)**

  * Hero section dengan identitas PKKMB
  * Countdown kegiatan
  * Event Series PKKMB

* 📅 **Event Series**

  * Rangkaian kegiatan PKKMB
  * Timeline acara

* 📖 **Informasi**

  * Tata tertib peserta
  * Ketentuan pakaian
  * Handbook (download/view)
  * Link Twibbon

* 🖼️ **Galeri**

  * Dokumentasi foto kegiatan (slider/carousel)

* 🏫 **Ormawa & UKM**

  * Informasi organisasi mahasiswa
  * Unit kegiatan mahasiswa

---

## 📂 Struktur Folder

```
/src
  /components     → Komponen UI (Navbar, Hero, Footer, dll)
  /sections       → Section halaman (Beranda, Event, Galeri, dll)
  /pages          → Routing halaman
  /assets         → Gambar & media
  /styles         → Styling tambahan
```

---

## ⚙️ Instalasi & Setup

1. Clone repository

```bash
git clone https://github.com/username/pkkmb-website.git
```

2. Masuk ke folder project

```bash
cd pkkmb-website
```

3. Install dependencies

```bash
npm install
```

4. Jalankan project

```bash
npm run dev
```

5. Buka di browser

```
http://localhost:3000
```

---

## 📦 Build Production

```bash
npm run build
npm start
```

---

## 🎨 Customisasi

Beberapa bagian yang bisa disesuaikan:

* Warna tema → `tailwind.config.js`
* Konten teks → di setiap file section
* Gambar & logo → folder `/assets`
* Countdown → komponen `Countdown.tsx`
